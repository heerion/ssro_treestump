# SSRO TREESTUMP

서울시립청소년미디어센터 스스로넷 청소년운영위원회 〈그루터기〉 소개 사이트.

## 폴더 구조

```
ssro-treestump/
├─ index.html            화면의 뼈대 (섹션 순서, 소개 문단)
├─ 404.html              존재하지 않는 주소로 들어왔을 때 보이는 화면
├─ robots.txt · sitemap.xml · site.webmanifest   검색·설치 관련 설정
├─ css/
│  ├─ style.css          색·글꼴·배치 (사이트 전체)
│  ├─ timeline-admin.css 편집기 공용 배치 + 연표 편집기 전용 규칙
│  └─ members-admin.css  위원 편집기 전용 배치
├─ js/
│  ├─ data.js            ★ 내용 (구성원, 연도별 활동, 연락처, 인스타그램)
│  ├─ timeline-core.js   나이테·연도 목록을 그리는 공용 함수 (메인 화면·편집기가 함께 씀)
│  ├─ member-core.js     위원 카드를 그리는 공용 함수 (메인 화면·편집기가 함께 씀)
│  └─ main.js            동작 (나이테, 아코디언, 폼, 등장 효과)
├─ admin/
│  ├─ timeline.html      ★ 연표 편집기 — 아래 '연표 편집기로 연혁 고치기' 참고
│  ├─ timeline-admin.js
│  ├─ members.html       ★ 위원 편집기 — 아래 '위원 편집기로 위원 소개 고치기' 참고
│  ├─ members-admin.js
│  └─ save-panel.js      '비밀번호로 저장' 패널 — 두 편집기가 함께 씀

│  ├─ save-site.js       두 편집기의 '저장'을 대신 처리하는 중계 서버 코드

   ├─ logo.png           로고 마크
   └─ members/           위원 편집기에서 올린 사진이 저장되는 곳
```

## 보는 방법

`index.html` 을 브라우저로 열면 바로 보입니다. 서버가 없어도 됩니다.

## 자주 고칠 곳 — `js/data.js`

### 위원 추가·수정

> 💡 코드를 직접 만지기보다 화면에서 편하게 하고 싶다면 아래 **'위원
> 편집기로 위원 소개 고치기'** 를 먼저 보세요. 사진도 편집기에서 올릴 수
> 있습니다. 여기 나온 방법은 편집기 없이 직접 고칠 때를 위한 것입니다.

`members` 배열에 한 줄 넣으면 카드가 자동으로 만들어집니다. 칸 수는 화면 폭에
맞춰 알아서 바뀌니 따로 손댈 것이 없습니다.

```js
{ role:"위원", name:"이름", term:"2026 · 1년차", word:"한 줄 소개", tags:["#태그"], photo:"" },
```

`photo` 는 `img/members/` 안에 있는 사진 파일 경로입니다(예:
`"img/members/ab12cd34.jpg"`). 비워 두면 이름 첫 글자가 들어간 동그라미가
대신 나옵니다. 사진을 직접 올릴 때는 파일을 `img/members/` 폴더에 넣고
경로를 정확히 맞춰 주세요 — 편집기를 쓰면 이 과정이 자동입니다.

### 활동 기록 추가

> 💡 코드를 직접 만지기보다 화면에서 편하게 하고 싶다면 아래 **'연표 편집기로
> 연혁 고치기'** 를 먼저 보세요. 여기 나온 방법은 편집기 없이 직접 고칠 때를
> 위한 것입니다.

`years` 안에 연도를 키로 넣습니다. 연도를 새로 추가하면 나이테도 한 겹
자동으로 늘어납니다.

```js
2027: [
  { m:"03", t:"활동 이름", d:"한두 문장 설명" }
],
```

`m` 은 월(두 자리), `t` 는 제목, `d` 는 설명입니다.

**2009~2022년처럼 이전 연도도 같은 자리에 넣습니다.** `years` 안에 연도만 추가하면
되고, 순서는 상관없습니다. 아예 적지 않은 해는 목록에서 '기록 없음'으로 나옵니다.
목록에는 **최근 5개년만 펼쳐서** 보이고, 그보다 오래된 해는 '펼치기' 버튼 안에
들어갑니다. 펼쳐 둔 5개년은 기록이 없어도 진한 글씨로 나오고, 접힌 구간에서
기록이 없는 해는 흐리게 표시됩니다.

> ⚠️ **새 연도를 넣을 때는 바로 앞 항목 끝의 `]` 뒤에 쉼표를 꼭 찍으세요.**
> 이걸 빠뜨리는 것이 화면이 안 나오는 가장 흔한 이유입니다.

### 문의 메일

`contact.email` 에 담당자 주소를 넣으면 문의 화면에 '메일 앱 열기' 버튼이
생깁니다. 비워 두면 내용을 복사하는 버튼만 나옵니다.

### 활동 사진 (인스타그램)

- **자동으로 채우기** — Behold, LightWidget, SnapWidget 같은 곳에서 계정을 한 번
  연결하면 붙여넣기용 코드를 줍니다. 그 코드를 `instagram.widget` 안에 통째로
  넣으세요. 그 뒤로는 새 글이 올라올 때마다 사이트에도 저절로 반영됩니다.
  (계정이 프로페셔널(비즈니스·크리에이터)이어야 연결됩니다.)
- **직접 고르기** — `instagram.posts` 에 공개 게시물 주소를 넣습니다. 이 방법은
  새 글마다 주소를 추가해야 합니다.
- 둘 다 비어 있으면 인스타그램으로 가는 안내 카드만 보입니다.

## 연표 편집기로 연혁 고치기 — `admin/timeline.html`

`js/data.js` 를 직접 열어 문법에 맞춰 고치는 대신, 브라우저 화면에서 활동
연혁(나이테)을 편집할 수 있는 도구입니다. 코드를 몰라도 됩니다.

1. 사이트를 올린 주소 뒤에 `/admin/timeline.html` 을 붙여 엽니다.
   (예: `https://your-domain.example/admin/timeline.html`. 로컬에서
   `index.html` 을 파일로 직접 열듯이 `admin/timeline.html` 을 여는 것도
   되지만, 아래 '다운로드' 기능은 서버에 올린 뒤에 써야 안정적으로 됩니다.)
2. 왼쪽에서 연도를 추가·삭제하고, 그 안의 활동(월·제목·설명)을 추가·삭제·순서
   변경합니다. 오른쪽 '미리보기' 에 실제 사이트와 똑같은 모습으로 바로
   반영됩니다.
3. 고치는 동안 내용은 이 브라우저에 자동으로 임시 저장됩니다(다른 사람에게는
   보이지 않고, 이 컴퓨터의 이 브라우저에만 남습니다). 창을 닫았다가 다시
   열면 이어서 할지 물어봅니다.
4. 다 고쳤으면 반영합니다. 두 가지 방법이 있어요.

### 방법 A · 비밀번호로 바로 저장 (추천)

**GitHub를 몰라도 됩니다.** 담당자에게 받은 비밀번호만 넣고 **저장** 버튼을
누르면 바로 사이트에 반영됩니다(보통 1분 안팎). 편집기가 직접 GitHub에
연결하는 게 아니라, 별도로 배포해 둔 작은 저장 중계 서버(Cloudflare Worker)에
비밀번호와 연표 내용만 보내고, 그 서버가 대신 GitHub에 커밋합니다. 위원들의
브라우저에는 GitHub 토큰이 전혀 남지 않습니다.

1. **비밀번호** 칸에 담당자에게 받은 비밀번호를 넣습니다.
2. **'비밀번호 확인'** 으로 잘 연결되는지 먼저 확인해도 되고, 바로
   **'저장'** 을 눌러도 됩니다.
3. **'이 브라우저에 비밀번호 기억하기'** 를 켜 두면 다음에 열 때 다시
   입력하지 않아도 됩니다. 공용 컴퓨터에서는 꺼 두는 걸 추천합니다.

이 방식을 쓰려면 저장소 관리자가 먼저 한 번 저장 중계 서버를 배포해야
합니다 — [`worker/README.md`](worker/README.md) 에 단계별로 정리해
뒀습니다(무료, 15~30분). 배포한 뒤 `admin/timeline-admin.js` 맨 위
`SAVE_ENDPOINT` 값에 배포 주소를 넣으면, 그 뒤로는 위원 누구나 비밀번호만
알면 됩니다. 아직 설정 전이라면 편집기의 **'관리자 설정'** 에 안내가 나옵니다.

### 방법 B · 수동으로 반영하기 (저장 서버 없이)

저장 중계 서버를 아직 만들지 않았거나, 파일을 직접 올리는 사람이 따로 있을
때 씁니다. '수동으로 반영하기' 를 펼치면 나옵니다.

- **data.js 다운로드** — 지금 사이트의 `js/data.js` 에서 연혁 부분만 바꾼
  새 `data.js` 파일을 내려받습니다. 이 파일로 기존 `js/data.js` 를 덮어쓴
  뒤, 평소처럼 깃허브 등에 다시 올리면 사이트에 반영됩니다.
- **연표 코드만 복사** — `years: { ... }` 부분의 코드만 복사합니다.
  `js/data.js` 를 열어 그 부분을 직접 붙여 넣고 싶을 때 씁니다.
- **js/data.js 내용으로 되돌리기** — 지금까지 편집기에서 바꾼 내용과
  임시 저장을 지우고, 실제 파일 내용으로 다시 시작합니다.

방법 A(저장 서버)가 설정되지 않은 상태에서는 여기서 바꾼 내용이 방문자에게
자동으로 보이지는 않고, 방법 B로 `data.js` 를 바꿔 다시 올려야 사이트에
반영됩니다. 구성원(`members`)이나 연락처 같은 다른 내용은 지금처럼
`js/data.js` 를 직접 고치거나, 구성원은 아래 위원 편집기를 씁니다.

## 위원 편집기로 위원 소개 고치기 — `admin/members.html`

위원 이름·역할·기수·한 줄 소개·태그·**사진**을 화면에서 편집하는 도구입니다.
연표 편집기와 구조가 같고(같은 저장 중계 서버를 씁니다), 사진은 고르는
즉시 브라우저에서 알맞은 크기로 줄인 뒤 **저장**을 누를 때 함께 올라갑니다
— 따로 이미지 호스팅 서비스에 가입할 필요가 없습니다.

1. `admin/members.html` 을 엽니다 (연표 편집기 머리글의 '위원 편집기'
   링크로도 갈 수 있습니다).
2. 위원을 추가·삭제·순서 변경하고, 각 위원의 정보를 채웁니다. **'사진
   선택'** 으로 사진을 고르면 미리보기에 바로 반영됩니다 — 이때는 아직
   저장되지 않은 상태입니다.
3. 연표 편집기와 같은 방법으로 저장합니다 — **비밀번호**를 넣고 **저장**을
   누르면 사진과 위원 정보가 함께 커밋됩니다(자세한 내용은 위 '연표
   편집기로 연혁 고치기'의 '방법 A' 참고). 저장 서버 주소는
   `admin/members-admin.js` 맨 위 `SAVE_ENDPOINT` 에 넣습니다 — 연표
   편집기와 같은 Worker 주소를 쓰면 됩니다.
4. 저장 서버 없이 쓰려면 '수동으로 반영하기'로 `data.js` 를 내려받거나
   코드만 복사할 수 있습니다. **다만 이 경우 사진은 자동으로 올라가지
   않으니**, 사진 파일을 직접 `img/members/` 폴더에 올리고 코드의
   `photo` 경로를 그 파일 이름에 맞게 고쳐야 합니다.

## 문의 접수 설정

`js/data.js` 의 `form.mode` 를 셋 중 하나로 바꾸면 됩니다. 서버는 필요 없습니다.

### 1) `"mailto"` — 기본값

방문자가 '문의 보내기' 를 누르면 메일 앱이 열리거나 내용이 복사됩니다.
접수 내역이 따로 쌓이지 않으니, 아래 둘 중 하나로 바꾸는 것을 권합니다.

### 2) `"google"` — 구글 폼에 쌓기 (추천 · 무료)

답변이 구글 시트에 자동으로 모입니다. 계정만 있으면 되고 비용이 없습니다.

1. 구글 폼을 새로 만들고 질문 4개를 만듭니다 — 이름 / 이메일 / 문의 유형 / 내용
2. 폼 편집 화면 오른쪽 위 `⋮` → **미리 채워진 링크 가져오기**
3. 각 칸에 아무 값이나 넣고 **링크 가져오기** → 주소 복사
4. 복사한 주소에 `entry.1234567=값` 이 질문마다 하나씩 들어 있습니다.
   그 번호들을 `form.google.entries` 에 옮겨 적습니다.
5. 폼 주소 `.../forms/d/e/`**`이 부분`**`/viewform` 을 `form.google.formId` 에 넣습니다.
6. `mode` 를 `"google"` 로 바꿉니다.
7. 답변은 구글 폼 **응답** 탭에서 보고, '스프레드시트로 보기' 를 누르면 시트로 쌓입니다.

```js
form: {
  mode: "google",
  google: {
    formId: "1FAIpQLSd...",
    entries: { name:"entry.111", email:"entry.222", type:"entry.333", message:"entry.444" }
  }
}
```

### 3) `"endpoint"` — 메일로 받기 (무료 서비스)

**Web3Forms** — 가입 없이 이메일만 넣으면 접수용 키를 보내 줍니다.

```js
form: {
  mode: "endpoint",
  endpoint: "https://api.web3forms.com/submit",
  extra: { access_key: "받은-키" }
}
```

**Formspree** — 가입 후 폼을 만들면 주소를 줍니다. 무료는 월 50건까지입니다.

```js
form: { mode: "endpoint", endpoint: "https://formspree.io/f/xxxxxx" }
```

### 개인정보 관련

폼에 '이름과 이메일 수집 동의' 체크가 들어 있습니다. 구글 시트나 서비스 대시보드에
쌓인 내역은 담당 선생님과 위원장 정도만 접근할 수 있게 공유 범위를 좁혀 두고,
답변이 끝난 문의는 지우는 편이 좋습니다.

자동 스팸을 막기 위해 사람 눈에 보이지 않는 칸을 하나 두었습니다. 그 칸이 채워져
들어오면 전송하지 않습니다.

## 화면이 안 보일 때

`js/data.js` 를 고친 뒤 화면이 비어 보이면, 아래쪽에 검은 안내 막대가 뜹니다.
거의 항상 아래 셋 중 하나입니다.

1. 앞 항목 끝에 쉼표( , )를 빠뜨렸다
2. 대괄호 `[ ]` 나 중괄호 `{ }` 의 짝이 맞지 않는다
3. 따옴표가 `" "` 가 아니라 `" "` 로 바뀌었다 (한글 입력기나 문서 편집기에서
   붙여넣을 때 자주 생깁니다)

더 정확한 위치는 브라우저에서 `F12` 를 누르고 Console 탭을 보면 몇 번째 줄인지
나옵니다. 고치기 전 파일을 복사해 두면 되돌리기 편합니다.
