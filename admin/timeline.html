GitHub에 저장 — 누르면 바로 반영

이 편집기는 서버 없이 브라우저에서만 동작하지만, GitHub 토큰을 한 번 넣어 두면 저장 버튼을 누르는 즉시 js/data.js 를 저장소에 직접 커밋합니다. 파일을 내려받아 옮길 필요가 없어요. 사이트에는 보통 1분 안팎이면 반영됩니다 (GitHub Pages/Netlify/Vercel이 커밋을 보고 자동으로 다시 배포하는 시간).

GitHub 연결 설정 연결 안 됨

GitHub에서 fine-grained 토큰 만들기 — Repository access는 이 저장소 하나만, Permissions → Contents는 Read and write로만 좁혀서 만드세요. 유효 기간도 짧게 잡는 걸 추천합니다. 토큰은 이 브라우저에만 저장되고 GitHub API로만 전송돼요. 공용 컴퓨터에서는 체크를 끄거나 아래 '토큰 지우기'로 끝난 뒤 지워 주세요.

수동으로 반영하기 (GitHub 연결 없이 쓸 때)

토큰을 쓰고 싶지 않거나 인터넷에 올리기 전 로컬에서만 확인할 때 씁니다. data.js 다운로드를 눌러 받은 파일로 js/data.js 를 바꾼 뒤, 평소 방법대로 다시 올려야 사이트에 반영됩니다.
