저장 — 비밀번호 한 번으로 바로 반영

GitHub 계정이나 토큰은 몰라도 됩니다. 담당자에게 받은 비밀번호를 넣고 저장을 누르면 바로 사이트에 반영돼요. 사진도 함께 올라갑니다. 사이트에는 보통 1분 안팎이면 나타납니다.

관리자 설정

이 편집기는 worker/README.md 안내대로 만든 저장 중계 서버(Cloudflare Worker)로 커밋합니다. 연표 편집기와 같은 서버를 씁니다. 처음 설정하는 관리자는 그 문서를 따라 서버를 배포한 뒤, admin/members-admin.js 맨 위 SAVE_ENDPOINT 값에 배포된 주소를 넣어 주세요 (연표 편집기에 이미 넣었다면 같은 주소를 넣으면 됩니다). 위원들은 이 설정을 몰라도 되고, 비밀번호만 알면 됩니다.

수동으로 반영하기 (저장 서버 없이 쓸 때)

저장 서버를 쓰지 않을 때 씁니다. 다만 이 방법으로는 사진은 자동으로 올라가지 않습니다 — 사진 파일을 직접 img/members/ 폴더에 올린 뒤, 아래 코드의 photo 경로를 그 파일 이름으로 맞춰 주세요.
